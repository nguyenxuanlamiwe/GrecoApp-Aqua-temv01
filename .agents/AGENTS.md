# GrecoApp — Project Rules

## Code Modification Policy

- **Chỉ được sửa code khi có yêu cầu rõ ràng từ user.**
- Không được tự ý chỉnh sửa, refactor, format, hay thêm/xóa code khi không được yêu cầu.
- Khi phân tích hoặc rà soát code, chỉ đọc và báo cáo — không thay đổi bất kỳ file nào.
- Nếu phát hiện vấn đề trong quá trình đọc code, chỉ được **báo cáo** cho user, không tự sửa.
